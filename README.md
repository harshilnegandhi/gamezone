# GameZone – The Ultimate Gaming Hub
Next.js 14 (App Router) + TypeScript + Tailwind CSS. No paid services or API keys needed.

## Run locally
    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start   # production check

## Replace images
Images live in `public/images/<name>.svg` (generated by `npm run images`). To use real artwork, save a licensed image (e.g. from Unsplash/Pexels or your own screenshots) as `public/images/<same-name>.jpg`, then change the extension in `components/PostCard.tsx`, `app/blog/[slug]/page.tsx` and `app/layout.tsx`. Use a 1200x630 PNG/JPG for `og-default` since social sites handle it better than SVG.

## Configure
- Set `NEXT_PUBLIC_SITE_URL` (Vercel env var) to your real domain for sitemap/canonicals.
- Edit `CONTACT_EMAIL` in `lib/posts.ts`.
- Articles are in `lib/posts.ts`; add an object to add a post.
- Newsletter has no backend; it tells visitors honestly that nothing is saved.

## GitHub + Vercel
    git init && git add . && git commit -m "GameZone"
    git branch -M main
    git remote add origin https://github.com/<you>/gamezone.git
    git push -u origin main
Then go to vercel.com → Add New Project → import the repo → Deploy (defaults work).
